# Trident menu updates

Обновления меню загружаются из GitHub Releases.

## Как выпустить обновление
1. Открой Releases → Draft a new release.
2. Укажи новый тег `menu-10`, затем `menu-11` и так далее. В первой сборке с обновлениями установлен номер 9.
3. Прикрепи ровно один APK с простым именем, например `Trident-menu-10.apk`.
4. Добавь описание изменений и опубликуй обычный Release (не draft и не prerelease).

APK должен иметь тот же package name и подпись, что и установленная сборка. При подготовке новой сборки увеличивай `Updater.BUILD` в исходниках до номера тега. Не публикуй ключ подписи или пароли в репозитории.

В меню: Обновления → Проверить обновления → Скачать обновление → Открыть загрузки / установить. Android запрашивает подтверждение установки.

Если Release ещё не создан, меню сообщает, что обновлений пока нет. Первая установка сборки с обновлениями выполняется вручную.
